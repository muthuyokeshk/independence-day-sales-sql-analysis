# Independence Day Sales Analysis 🇮🇳

## Project Overview

This project contains SQL-based sales analysis queries created as part of an Independence Day SQL Coding Contest.

The project uses a sales dataset containing customer, location, product, category, quantity, price, discount, and sales information.

## Dataset

The `sales` table contains the following columns:

- SaleID
- SaleDate
- CustomerName
- City
- State
- Product
- Category
- Quantity
- Price
- Discount
- SalesAmount

## SQL Concepts Covered

This project demonstrates the following SQL concepts:

- Basic SQL Queries
- Aggregate Functions
- GROUP BY and HAVING
- Date and Time Functions
- CASE Statements
- Subqueries
